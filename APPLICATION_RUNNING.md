## 🆘 Troubleshooting

### Frontend not loading?
1. Ensure port 5173 is accessible
2. Check browser console for errors
3. Verify backend is running at port 8000

### Can't login?
1. Use correct credentials (see above)
2. Check backend is responding at http://localhost:8000/docs
3. Clear browser cache and cookies

### API errors?
1. Check OpenAI API key is valid
2. Verify .env file exists in backend directory
3. Check backend logs for error messages

### Upload failures?
1. File size must be < 200MB
2. Supported formats: CSV, Excel, JSON
3. Check backend logs for parsing errors
